# IT Support — Knowledge Base

## Overview
This document covers IT infrastructure issues including cloud platform disruptions, office-wide connectivity problems, server room hardware failures, VPN-router issues, and SaaS platform outages.

---

## Issue: Cloud SaaS Platform Disruption

### Symptoms
- Certain features of the Cloud SaaS platform are not functioning
- Workflow interruptions affecting business operations
- Users unable to access dashboards or submit data

### Resolution Steps
1. Check the SaaS provider's status page for active incidents.
2. Log out and log back in to refresh your session token.
3. Clear browser cache and disable extensions.
4. If the issue is platform-wide, escalate to IT immediately with affected user list.
5. IT will coordinate with the SaaS vendor for resolution and provide ETR updates every 30 minutes.

---

## Issue: Office-Wide Connectivity Problems

### Symptoms
- Multiple devices (headsets, printers, workstations) losing connectivity simultaneously
- Network disruptions affecting daily operations across the office

### Resolution Steps
1. Check if the issue is isolated to one floor or affects the entire building.
2. Restart the primary network switch and router.
3. Verify all network cables are securely connected.
4. Check DHCP server logs for IP conflicts.
5. Contact IT Network team immediately for on-site diagnosis if restart does not resolve.
6. Temporary workaround: use mobile hotspot for critical tasks while IT investigates.

## Issue: Server Room Overheating

### Symptoms
- Server room temperature alerts triggered
- Malfunctioning PC fan (PC-Lüfter) causing heat buildup
- Risk of hardware damage and data loss

### Resolution Steps
1. Immediately alert the IT Infrastructure team — this is a Critical priority issue.
2. Do NOT attempt to fix hardware without authorisation.
3. Shut down non-critical servers to reduce heat load.
4. Ensure the CRAC (Computer Room Air Conditioning) unit is operational.
5. IT will dispatch a hardware engineer within 1 hour for Critical issues.
6. Document all affected equipment for insurance and incident reporting.

## Issue: VPN-Router Connectivity Disruption

### Symptoms
- VPN-router connectivity failing on multiple devices
- Remote telemedicine systems and EMR integrations affected
- Restarting devices and resetting router has not resolved the issue

### Resolution Steps
1. Check router firmware version and update if outdated.
2. Verify VPN gateway IP and port settings are correctly configured.
3. Review firewall rules — ensure VPN ports (UDP 500, 4500) are not blocked.
4. Check for IP address conflicts on the network.
5. If EMR/telemedicine systems are affected, escalate to Critical priority immediately.
6. Contact the network vendor for advanced diagnostics if internal steps fail.

---

## Issue: QuickBooks Online Login Failure

### Symptoms
- Unable to log in to QuickBooks Online despite correct credentials
- Error message appears on every login attempt
- Issue persists for multiple days

### Resolution Steps
1. Reset your password via the QuickBooks Online forgot password link.
2. Clear browser cache and try an incognito/private window.
3. Disable browser extensions, especially ad blockers.
4. Try a different browser or device.
5. Contact Intuit QuickBooks Support if the issue persists after password reset.
6. IT can assist with SSO (Single Sign-On) configuration issues if applicable.
