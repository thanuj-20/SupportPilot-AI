## Issue: Office 365 Applications Not Opening on MacBook Air

### Symptoms
- Employees unable to open Excel, PowerPoint, Word on MacBook Air
- Valid licenses exist but applications fail to launch
- Issue started after a recent macOS update

### Resolution Steps
1. Open System Preferences > Security & Privacy and check if Office apps are blocked.
2. Run Microsoft AutoUpdate: Applications > Microsoft AutoUpdate.
3. Sign out of all Microsoft 365 accounts and sign back in.
4. If the issue is license-related, verify the license assignment in the Microsoft 365 Admin Centre.
5. IT can re-assign the license: Admin Centre > Users > Active Users > Licenses.
6. If the macOS update caused the issue, check Microsoft's macOS compatibility page.
7. As a temporary workaround, use Office 365 Online (office.com) in the browser.

## Issue: Account Incident Summary Request

### Symptoms
- HR or management requesting a summary of a recent account incident
- Need to understand the incident's impact and determine appropriate measures

### Resolution Steps
1. Submit an Incident Summary Request via the IT ticketing system.
2. Include the incident date, affected systems, and your employee ID.
3. IT Security will prepare a formal Incident Report within 3 business days.
4. The report will include: timeline, root cause, impact assessment, and remediation steps.
5. Confidential incidents require manager-level authorisation to access.

## Issue: QuickBooks Online Access for Employees

### Symptoms
- Employee unable to log in to QuickBooks Online
- Login fails despite correct credentials
- Error message appears on every attempt

### Resolution Steps
1. Verify the employee has an active QuickBooks Online licence assigned.
2. Reset the password via the QuickBooks Online admin portal.
3. Check if the account is locked due to multiple failed login attempts.
4. Clear browser cache and try in an incognito window.
5. If SSO is configured, verify the SSO settings in the Microsoft 365 Admin Centre.
6. Contact Intuit Support if the issue persists after licence verification.

## Issue: New Employee IT Access Setup

### Symptoms
- New employee needs access to company systems, email, and applications
- Onboarding IT setup not completed before start date

### Resolution Steps
1. Submit a New Employee Access Request at least 5 business days before the start date.
2. Required information: full name, department, manager name, start date, required applications.
3. IT will provision: email account, VPN access, laptop setup, and application licences.
4. Access credentials will be delivered to the manager on the employee's first day.
5. IT onboarding session scheduled for Day 1 to walk through systems and security policies.
